This website is a web-based transparency and monitoring platform designed to reduce corruption in flood-control projects in the Philippines. It empowers both government administrators and local communities to track, validate, and report on public infrastructure projects, promoting accountability and ensuring that flood-control projects are properly executed.

---

## Overview

This website enables real-time monitoring of flood-control projects through geolocation, AI-assisted verification, and transparent public data. The platform ensures that project progress is visible to both officials and residents, helping identify ghost projects, delays, and budget inconsistencies.

---

## Objectives

- Increase transparency in government-funded flood-control projects.
- Detect ghost or suspicious projects using AI-driven analysis.
- Enable communities to monitor nearby flood-control infrastructures.
- Provide administrators with AI-assisted contractor recommendations.
- Offer tamper-resistant community reporting with geolocation data.
- Create a publicly accessible transparency dashboard.

---

## User Types

### Admin Users

- Government and agency personnel who manage and verify project data.
- Access to advanced project dashboards, AI recommendations, and reports.

### Community Users

- Citizens who monitor nearby projects and submit on-site reports.
- Can view project locations, status, documents, and routes.

---

# Features

## 1. Project Management (Admin)

- Add and manage flood-control projects.
- Upload and update procurement documents, progress photos, and status.
- Input contractor, budget, timeline, and project details.
- Assign projects for inspection or verification.

---

## 2. AI-Assisted Contractor Recommendation (Admin)

- AI analyzes contractor history, success rate, project type, location match, and budget fit.
- Provides suggested contractors with explanation and reasoning.
- Helps reduce favoritism and increase data-driven decision-making.

---

## 3. AI Ghost Project Detection

The system can identify potentially suspicious or ghost projects using:

- Community-submitted geotagged images.
- Comparison between reported progress and expected timeline.
- Contractor history and project performance patterns.
- Budget anomalies based on typical costs for similar projects.
- Lack of physical progress evidence in collected photos.

This generates a risk score and flags projects for admin inspection.

---

## 4. Community Location-Based Project Viewer

- When users log in, the system requests GPS location.
- Displays all nearby flood-control projects on:
  - Map view
  - List view
- Clicking a project shows:
  - Project details
  - Contractor information
  - Status and timeline
  - Uploaded documents
  - Route to the project site through integrated web mapping

---

## 5. Tamper-Proof Community Reporting

- Users submit reports using the web app’s camera integration.
- Only live-capture photos (no gallery uploads).
- Automatically captures:
  - GPS coordinates
  - Timestamp
  - Device/browser metadata
- AI classifies the report content:
  - No work visible
  - Partial progress
  - Completed work
  - Damaged or defective area
  - Wrong location

Admins can label reports as "For Inspection" or "Verified".

---

## 6. Transparency Dashboard

A public-facing dashboard displays:

- All projects in the system
- Status and progress
- Budget and timeline information
- Contractor details
- Latest community reports
- Verified vs unverified projects

This ensures open access to project information for all citizens.

---

## 7. SMS Notification System

Registered community members can receive SMS alerts for:

- Projects flagged as suspicious
- New reports in their local area
- Project status changes or inspections scheduled
- Completed or delayed project updates

# Identified Gaps & Solutions

### 1. Incomplete Data Sources

**Solution:** Start with pilot areas; allow admin validation; crowdsource missing details.

### 2. Fake Reports or Manipulated Images

**Solution:** Enforce live camera capture with location + timestamp metadata.

### 3. AI Bias in Contractor Recommendation

**Solution:** Combine deterministic scoring with AI reasoning.

### 4. Privacy and Legal Concerns

**Solution:** Only flag projects as “Under Review” before making public.
